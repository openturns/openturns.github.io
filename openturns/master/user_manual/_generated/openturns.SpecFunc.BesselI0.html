BesselI0¶

BesselI0(x)¶

Modified first kind Bessel function of order 0.

Parameters:
xfloat
Returns:
resultfloat

Notes

The following ResourceMap keys are used:

  • SpecFunc-MaximumIteration (UnsignedInteger, default: 1000).

  • SpecFunc-Precision (Scalar, default: 2e-16).

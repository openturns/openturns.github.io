class QuadraticProblem(*args)¶

Quadratic optimization problem.

Warning

This class is experimental and likely to be modified in future releases. To use it, import the openturns.experimental submodule.

The rows of define the linear constraints: row reads , where and are the lower and upper bounds of the constraint interval. A one-sided constraint is obtained with an infinite bound. Examples

Define and solve a bounded quadratic problem:

>>> import openturns as ot
>>> import openturns.experimental as otexp
>>> Q = ot.SymmetricMatrix([[2.0, 0.0], [0.0, 2.0]])
>>> c = [-2.0, -4.0]
>>> bounds = ot.Interval([0.0, 0.0], [0.5, 10.0])
>>> problem = otexp.QuadraticProblem(Q, c, bounds)
>>> algo = otexp.HiGHS(problem)
>>> algo.run()
>>> result = algo.getResult()
>>> x_star = result.getOptimalPoint()

Build the equivalent least-squares problem :

>>> A = ot.Matrix([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])
>>> b = [1.0, 2.0, 3.0]
>>> problem = otexp.QuadraticProblem.FromLeastSquares(A, b, bounds)
>>> problem.getConstant()
14.0

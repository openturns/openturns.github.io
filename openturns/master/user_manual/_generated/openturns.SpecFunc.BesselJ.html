BesselJ¶

BesselJ(nu, x)¶

First kind Bessel function of order nu.

Parameters:
nufloat

Order, finite. Integer orders accept any finite x by reflection; noninteger orders require x nonnegative.

xfloat

Argument, finite; must be nonnegative when nu is not an integer.

Returns:
resultfloat

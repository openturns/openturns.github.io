dNonCentralStudentAlt0¶

dNonCentralStudentAlt0(*args)¶

PDF of the non-central Student distribution for .

This is an alternative algorithm used when the degrees of freedom parameter is zero.

Parameters:
nufloat

Degrees of freedom. Must be 0 for this method.

deltafloat

Non-centrality parameter.

xfloat

Quantile.

precisionfloat, optional

Precision of the integration. Default is 1e-12.

maximumIterationint, optional

Maximum number of iterations. Default is 50.

Returns:
pdffloat

The value of the PDF.

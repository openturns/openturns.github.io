LauricellaF_A¶

LauricellaF_A(a, b, c, x)¶

Lauricella hypergeometric function of type .

where , , and denotes the rising factorial. The series converges for . The evaluation uses an exponential generating function to avoid computing large multinomial coefficients, see [exton1976]. When the series does not converge before its maximum degree, the function returns NaN so that the caller can use a fallback.

Parameters:
afloat
bsequence of float
csequence of float
xsequence of float
Returns:
resultfloat

The value of the function, or NaN if the series cannot be evaluated.

Raises:
TypeErrorIf b, c and x do not have the same dimension.

Notes

The following ResourceMap keys are used:

  • SpecFunc-LauricellaMaximumDegree (UnsignedInteger, default: 1024): maximum degree of the Lauricella series.

  • SpecFunc-LauricellaTolerance (Scalar, default: 1.0e-14): relative tolerance of the Lauricella series. The value must lie in .

Examples

>>> import openturns as ot
>>> value = ot.SpecFunc.LauricellaF_A(1.5, [2.0], [3.0], [0.5])

BasisOrthonormalizationFactory¶

class BasisOrthonormalizationFactory(*args)¶

Basis orthonormalization factory.

Warning

This class is experimental and likely to be modified in future releases. To use it, import the openturns.experimental submodule.

This class computes a finite set of orthonormal functions from the first elements of a source OrthogonalBasis, with respect to a target measure. It uses a BasisOrthonormalizationAlgorithm to compute the orthonormal basis and a GaussLPQuadrature built from the orthonormal functions and the target measure to construct quadrature rules. The basis comes from the QR factorization of the weighted design matrix when the integration rule exposes its nodes, and from the Cholesky factorization of the Gram matrix for opaque rules.

The source basis carries an instrumental measure, against which its functions are naturally orthogonal. The target measure is the measure against which the orthonormal basis is built. The two measures must have the same dimension and the support of the target measure must be contained in the support of the instrumental measure; an exception is raised otherwise. A discrete instrumental measure is exempt from the range check.

The initial functions do not need to be orthonormal with respect to the target measure: the factory computes an orthonormal basis of the vector space they span.

The integration algorithm is not a constructor argument: the default target-measure-adapted rule is used unless setIntegrationAlgorithm() replaces it, so that the basis, the target measure and the rule are always set consistently.

Parameters:
basisOrthogonalBasis

Source orthogonal basis whose first elements are orthonormalized. Its measure is the instrumental measure.

targetMeasureDistribution

Target measure against which the orthonormal basis is built.

sizeint

Number of first elements of the source basis to orthonormalize. It must be positive.

Examples

>>> import openturns as ot
>>> import openturns.experimental as otexp
>>> dim = 2
>>> distribution = ot.JointDistribution(
...     [ot.Uniform(-1.0, 1.0)] * dim, ot.FrankCopula(4.0))
>>> legendreBasis = ot.OrthogonalProductPolynomialFactory(
...     [ot.LegendreFactory()] * dim)
>>> factory = otexp.BasisOrthonormalizationFactory(
...     legendreBasis, distribution, 6)
>>> factory.getSize()
6
>>> f0 = factory.build(0)

buildQuadrature(n)¶

Build a quadrature rule.

Build a quadrature rule integrating the first n orthonormal functions against the target measure. Uses the Gauss-LP approach: linear programming followed by clustering and local refinement. The returned number of nodes is at most n: a natural linear-programming support smaller than n is preserved. The moments are reproduced up to the refinement tolerance; when the residual exceeds it, a warning is logged and the best rule found is returned.

In Python, the two outputs are returned as a tuple and can be unpacked as nodes, weights = factory.buildQuadrature(n).

Note

The linear program requires HiGHS support. When OpenTURNS is built without HiGHS, the builder falls back to a refined measure-adapted tensor rule and emits a warning; it raises an exception when that rule has fewer than n nodes.

Parameters:
nint

Number of orthonormal functions whose moments are reproduced.

Returns:
nodesSample

The quadrature nodes.

weightsPoint

The quadrature weights.

buildQuadratureRule(n)¶

Build a quadrature rule as a weighted experiment.

Builds the rule with GaussLPQuadrature from the orthonormal functions and the target measure, and returns it as a WeightedExperiment whose implementation is the immutable GaussLPQuadratureRule. The rule stores the nodes, the weights and the target measure; its size is the actual number of nodes, which is at most n.

Note

The linear program requires HiGHS support. When OpenTURNS is built without HiGHS, the builder falls back to a refined measure-adapted tensor rule and emits a warning; it raises an exception when that rule has fewer than n nodes.

Parameters:
nint

Number of orthonormal functions whose moments are reproduced.

Returns:
ruleWeightedExperiment

The quadrature rule as a weighted experiment, whose implementation is a GaussLPQuadratureRule.

setIntegrationAlgorithm(integrationAlgorithm)¶

Accessor to the integration algorithm.

Any IntegrationAlgorithm can be used, including an ExperimentIntegration built from any weighted experiment. The experiment is validated when the orthonormal basis is computed. For an experiment, a continuous experiment distribution must be the target measure, and its instrumental distribution must contain the support of the target measure, otherwise an exception is raised. If the experiment distribution does not implement equality, the equality check is skipped and the caller is responsible for its compatibility with the target measure. A discrete experiment such as FixedExperiment is exempt from the equality and range checks because its distribution is the empirical measure supported by its nodes.

Parameters:
integrationAlgorithmIntegrationAlgorithm

Integration algorithm.

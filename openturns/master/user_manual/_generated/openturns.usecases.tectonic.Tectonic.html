Tectonic¶

class Tectonic¶

Tectonic site-mean directions with elliptical dispersion (reduced synthetic stand-in).

Kent-distributed unit vectors on the sphere mimicking a paleomagnetic collection from a tectonized area, where the directional dispersion is markedly elliptical (same MagIC frame as the Paleomagnetism use case). Each row is a site-mean direction stored as Cartesian components (x, y, z). The reference parameters are and with identity orientation. The sample was drawn with Kent (seed 23456).

Attributes:
directionsSample

150 site-mean directions (unit vectors).

Methods

getReferenceBeta()

Reference ovalness.

getReferenceKappa()

Reference concentration.

Examples

>>> from openturns.usecases import tectonic
>>> data = tectonic.Tectonic().directions
>>> print(data.getSize(), data.getDimension())
150 3

class ChristoffelSubsampleExperiment(*args)¶

Christoffel subsample experiment.

Warning

This class is experimental and likely to be modified in future releases. To use it, import the openturns.experimental submodule.

Given an orthonormal basis of and a target size , the experiment works with the first basis functions, where is the largest dimension supplied by the basis: with an inexhaustible basis, and is tried until the basis supplies functions. It draws a pool of points from the ChristoffelDistribution associated to these functions, sized by ChristoffelSubsampleExperiment-PoolOversamplingFactor times , then greedily thins the pool down to points. When the thinned design is numerically unusable, the pool is doubled with fresh draws, keeping the existing points, up to ChristoffelSubsampleExperiment-PoolMaxOversamplingFactor times , and thinned again. The default Removal method drops pool points while keeping the largest smallest Gramian eigenvalue and no reweighting; the Barrier method is a forward barrier greedy selection with reweighting, clamped strictly inside the current spectrum so rank-deficient steps stay well-defined. Each kept point carries a weight proportional to , the density ratio of the reference measure over the Christoffel distribution, times the barrier weight for the Barrier method.

The sizing follows the budget theorem: from Christoffel draws with (Theorem 2.3 of Cohen and Dolbeault [cohendolbeault2020]) one extracts points with a good approximation; the pool above is the practical pool, used at the price of weaker guarantees. The budget sizes the pool draws, not the space dimension, which stays . With an inexhaustible basis , so the default Removal thinning costs approximately ( iterations scoring candidates with an eigen solve each); keep moderate in that case. The implementation checks the frame bounds and can return a design satisfying them.

Notes

The following ResourceMap keys are used:

  • ChristoffelSubsampleExperiment-PoolOversamplingFactor (Scalar, default: 2.0): candidate pool size as a multiple of the target size.

  • ChristoffelSubsampleExperiment-PoolMaxOversamplingFactor (Scalar, default: 16.0): cap of the adaptive pool growth as a multiple of the target size, reached by doubling a numerically unusable pool.

  • ChristoffelSubsampleExperiment-FrameTolerance (Scalar, default: 0.5): half-width of the accepted frame eigenvalue band around 1.

  • ChristoffelSubsampleExperiment-ThinningMethod (String, default: Removal): greedy thinning method. Possible values: Barrier, Removal.

  • ChristoffelSubsampleExperiment-BarrierStep (Scalar, default: 1.0): barrier advance per selection step of the Barrier method.

  • ChristoffelSubsampleExperiment-BarrierRegularization (Scalar, default: 1e-8): safety gap keeping the barriers strictly inside the spectrum.

Examples

>>> import openturns as ot
>>> import openturns.experimental as otexp
>>> ot.RandomGenerator.SetSeed(0)
>>> factory = ot.OrthogonalProductPolynomialFactory([ot.Uniform(-1.0, 1.0)])
>>> basis = ot.OrthogonalBasis(factory)
>>> experiment = otexp.ChristoffelSubsampleExperiment(basis, 60)
>>> print(experiment.getSpaceDimension())
60
>>> sample, weights = experiment.generateWithWeights()
>>> print(len(sample), len(weights))
60 60

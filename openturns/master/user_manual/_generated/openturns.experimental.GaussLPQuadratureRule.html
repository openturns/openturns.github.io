GaussLPQuadratureRule¶

class GaussLPQuadratureRule(*args)¶

Immutable Gauss-LP quadrature rule.

Warning

This class is experimental and likely to be modified in future releases. To use it, import the openturns.experimental submodule.

This class stores the nodes and weights produced by GaussLPQuadrature. Unlike the builder, its size is known when it is constructed: it is the number of nodes actually returned by the algorithm, which may be smaller than the requested number of functions. The stored distribution is the measure against which the rule was built.

The rule is immutable: setSize() rejects any size other than the stored one and setDistribution() always raises, so a built rule stays fixed. generateWithWeights() always returns the same nodes and weights, and isRandom() returns False.

Parameters:

The quadrature nodes.

weightsPoint

The quadrature weights, one per node.

Examples

>>> import openturns as ot
>>> import openturns.experimental as otexp
>>> measure = ot.JointDistribution([ot.Uniform(0.0, 1.0)] * 2)
>>> functions = [ot.SymbolicFunction(['x', 'y'], [formula])
...              for formula in ['1.0', 'x', 'y', 'x * y']]
>>> builder = otexp.GaussLPQuadrature(functions, measure)
>>> rule = builder.buildRule(3)
>>> nodes, weights = rule.generateWithWeights()

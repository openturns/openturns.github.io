Paleomagnetism¶

class Paleomagnetism¶

Paleomagnetic site-mean directions (reduced synthetic stand-in).

Fisher-distributed unit vectors on the sphere mimicking a paleomagnetic site collection as archived by the MagIC database (earthref.org): each row is a site-mean direction stored as Cartesian components (x, y, z). The reference direction is declination 35 degrees, inclination 50 degrees, with a concentration typical of a well-defined volcanic site (see e.g. the PmagPy Fisher-mean notebook). The sample was drawn with VonMisesFisher (seed 12345).

Attributes:
directionsSample

150 site-mean directions (unit vectors).

Methods

getReferenceKappa()

Reference concentration.

getReferenceMeanDirection()

Reference Fisher mean direction (dec 35 deg, inc 50 deg).

Examples

>>> from openturns.usecases import paleomagnetism
>>> data = paleomagnetism.Paleomagnetism().directions
>>> print(data.getSize(), data.getDimension())
150 3

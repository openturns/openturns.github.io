Notes

The simulation sensitivity analysis is based on:

  • in the first usage, the inputSample and outputSample given, with optional importance weights:

  • in the second usage, the samples which have been stored by the function defining the event. Care if the sample is not a statistical sample: post treatment proposed by the object might not be right.

  • in the third usage, the samples generated by the EventSimulation that produced simulationRes. This usage loads the input/output sample histories but does not recover importance weights, so calculations use uniform weights by default. The histories contain every evaluation memoized by the event model. Clear that history before running the simulation if it holds unrelated evaluations, such as a design-point search. For importance sampling, use the first usage with explicit weights, or set them afterwards with setWeights(), using only the simulation draws.

For a failure event with input density , the event probability sensitivity is estimated by , the mean point in the event domain by , with the importance weights. When the sample is mapped to physical space, the sample-based constructor must receive the original physical event, not the StandardEvent: this ensures sensitivities use the physical distribution’s score and parameters. For a simulation in the standard space, map the standard input sample back to the physical space and compute the weights as the ratio of the standard density over the importance density.

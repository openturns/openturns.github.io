ProbabilitySimulationResult¶

class ProbabilitySimulationResult(*args)¶

Handle to any concrete simulation result, preserving its dynamic type.

This handle stores e.g. NAISResult, SubsetSamplingResult or CrossEntropyResult without slicing them. Generic quantities are readable directly; concrete details are accessible through getImplementation(), which returns a copy of the concrete result with its dynamic type.

Available constructors:

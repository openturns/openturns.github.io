Notes

Refer to the least squares context and Least squares problems numerical methods to get details.

This class solves the least squares problem for each output marginal defined by equation (5) in the least squares context.

The finite discrete distribution based on the input sample and the weights defines the inner product that will be used to solve the least squares problem.

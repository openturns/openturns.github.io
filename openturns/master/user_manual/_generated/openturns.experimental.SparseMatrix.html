SparseMatrix¶

class SparseMatrix(*args)¶

Compressed sparse column matrix.

Warning

This class is experimental and likely to be modified in future releases. To use it, import the openturns.experimental submodule.

This class stores a matrix in the compressed sparse column (CSC) format, which is the format expected by sparse solvers: the non-zero coefficients are stored column by column, together with the row index of each coefficient and the offset of the first coefficient of each column.

The constructor from triplets builds the canonical form: the row indices are sorted within each column and the values of duplicate (row, column) coordinates are summed. Row and column indices are checked against the dimensions.

Parameters:

Number of rows. Default is 0.

nbColumnsint, optional

Number of columns. Default is 0.

Row index of each triplet, used by the constructor from triplets.

columnIndicessequence of int, optional

Column index of each triplet, used by the constructor from triplets.

valuessequence of float, optional

Value of each triplet, used by the constructor from triplets.

Notes

The compressed sparse column layout is available through getColumnPointer(), getRowIndices() and getValues(). The column pointer has size and starts at 0, so that column holds the coefficients of indices getColumnPointer()[j] to getColumnPointer()[j + 1] - 1.

The stored representation is canonical: the row indices are sorted within each column and each (row, column) coordinate is stored at most once. The coefficients can be read and written by index, and a coefficient which is not stored yet is inserted at its place when it is assigned.

Explicit zeros may be stored: they are kept in the sparse layout, and skipped when the matrix is converted to a dense matrix or handed over to a solver. Use FromDenseMatrix() to build a sparse matrix from a dense one, which drops the zero coefficients.

Examples

>>> import openturns as ot
>>> import openturns.experimental as otexp
>>> matrix = otexp.SparseMatrix(3, 2, [0, 2, 0], [0, 1, 0], [1.0, 2.0, 3.0])
>>> print(matrix.getNbNonZeros())
2
>>> print(matrix.getColumnPointer())
[0,1,2]
>>> print(matrix.asDenseMatrix())
[[ 4 0 ]
 [ 0 0 ]
 [ 0 2 ]]
>>> matrix[1, 1] = 7.0
>>> print(matrix.getNbNonZeros())
3
>>> print(matrix.getRowIndices())
[0,1,2]
>>> print(matrix.asDenseMatrix())
[[ 4 0 ]
 [ 0 7 ]
 [ 0 2 ]]

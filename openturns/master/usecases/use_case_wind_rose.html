The Wind Rose model¶

This use case collects wind headings at 100 m for wind-energy siting studies. The headings mimic daily means derived from ERA5 reanalysis (Copernicus CDS) (u, v) components converted to compass headings. Each row is a heading in radians in [0, 2 pi). The headings are modelled by a wrapped normal distribution.

The dataset is a reduced synthetic stand-in (365 daily headings drawn with WrappedNormal): the reference parameters are mu = 2.6 rad and sigma^2 = 0.8.

Workflow¶

  • Fit WrappedNormalFactory on the annual series.

  • Run the Rayleigh test against the uniform distribution and forecast the modal direction for turbine yaw alignment.

References¶

  • ERA5 reanalysis, Copernicus Climate Data Store (hourly (u, v) fields).

Load the use case¶

We can load this model from the use cases module as follows :

>>> from openturns.usecases.wind_rose import WindRose
>>> m = WindRose()
>>> # Load the 365 daily wind headings (radians in [0, 2 pi))
>>> data = m.directions

API documentation¶

class WindRose

Daily wind directions at 100 m (reduced synthetic stand-in).

Circular data mimicking one year of daily wind headings derived from ERA5 reanalysis (Copernicus CDS) (u, v) components converted to compass headings. Each row is a heading in radians in [0, 2 pi). The reference wrapped-normal parameters are mu = 2.6 rad and sigma^2 = 0.8. The sample was drawn with WrappedNormal (seed 78901).

Attributes:
directionsSample

365 daily wind headings (radians).

Methods

getReferenceMu()

Reference mean heading (radians).

getReferenceSigma2()

Reference circular variance.

Examples

>>> from openturns.usecases import wind_rose
>>> data = wind_rose.WindRose().directions
>>> print(data.getSize(), data.getDimension())
365 1

Reference mean heading (radians).

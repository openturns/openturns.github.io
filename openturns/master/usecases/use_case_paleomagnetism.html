The Paleomagnetism model¶

This use case collects site-mean remanent magnetization directions as archived by the MagIC database (earthref.org). Each direction is a unit vector of the sphere , stored through its Cartesian components . For a tectonically stable volcanic site the dispersion around the mean direction is isotropic and modelled by a von Mises-Fisher distribution with density .

The dataset is a reduced synthetic stand-in (150 directions drawn with VonMisesFisher): the reference mean direction is declination 35 degrees, inclination 50 degrees, with a concentration typical of a well-defined site (see the PmagPy Fisher-mean notebook for the same computation on real data).

Workflow¶

  • Fit VonMisesFisherFactory on the directions.

  • Suggested next step: compare the estimated mean direction and concentration to the PmagPy Fisher mean of a matching MagIC site.

References¶

  • MagIC database, earthref.org (open site-mean direction compilations).

  • PmagPy Fisher-mean notebook (open reference implementation).

  • Fisher R.A., “Dispersion on a sphere”, Proc. R. Soc. Lond. A 217, 1953.

Load the use case¶

We can load this model from the use cases module as follows :

>>> from openturns.usecases.paleomagnetism import Paleomagnetism
>>> m = Paleomagnetism()
>>> # Load the 150 site-mean directions (unit vectors)
>>> data = m.directions

API documentation¶

class Paleomagnetism

Paleomagnetic site-mean directions (reduced synthetic stand-in).

Fisher-distributed unit vectors on the sphere mimicking a paleomagnetic site collection as archived by the MagIC database (earthref.org): each row is a site-mean direction stored as Cartesian components (x, y, z). The reference direction is declination 35 degrees, inclination 50 degrees, with a concentration typical of a well-defined volcanic site (see e.g. the PmagPy Fisher-mean notebook). The sample was drawn with VonMisesFisher (seed 12345).

Attributes:
directionsSample

150 site-mean directions (unit vectors).

Methods

getReferenceKappa()

Reference concentration.

getReferenceMeanDirection()

Reference Fisher mean direction (dec 35 deg, inc 50 deg).

Examples

>>> from openturns.usecases import paleomagnetism
>>> data = paleomagnetism.Paleomagnetism().directions
>>> print(data.getSize(), data.getDimension())
150 3

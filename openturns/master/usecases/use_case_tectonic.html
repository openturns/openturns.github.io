The Tectonic model¶

This use case collects site-mean directions from a tectonized area, in the same MagIC frame (earthref.org) as the paleomagnetism use case. Here the directional dispersion is markedly elliptical and modelled by a Kent distribution [kent1982] with density on .

The dataset is a reduced synthetic stand-in (150 directions drawn with Kent): the reference parameters are , with identity orientation.

Workflow¶

  • Fit KentFactory on the directions.

  • Suggested next step: compare and to the Directional package fit of matching data and draw the 95% confidence oval.

References¶

  • MagIC database, earthref.org (sites with marked ellipticity).

  • Directional R/C++ package (Kent reference implementation).

Load the use case¶

We can load this model from the use cases module as follows :

>>> from openturns.usecases.tectonic import Tectonic
>>> m = Tectonic()
>>> # Load the 150 site-mean directions (unit vectors)
>>> data = m.directions

API documentation¶

class Tectonic

Tectonic site-mean directions with elliptical dispersion (reduced synthetic stand-in).

Kent-distributed unit vectors on the sphere mimicking a paleomagnetic collection from a tectonized area, where the directional dispersion is markedly elliptical (same MagIC frame as the Paleomagnetism use case). Each row is a site-mean direction stored as Cartesian components (x, y, z). The reference parameters are and with identity orientation. The sample was drawn with Kent (seed 23456).

Attributes:
directionsSample

150 site-mean directions (unit vectors).

Methods

getReferenceBeta()

Reference ovalness.

getReferenceKappa()

Reference concentration.

Examples

>>> from openturns.usecases import tectonic
>>> data = tectonic.Tectonic().directions
>>> print(data.getSize(), data.getDimension())
150 3

The Four Branch function¶

The Four Branch function is a 2D limit state function introduced by Schueremans and van Gemert (2005) [Schueremans2005] as a benchmark for structural reliability analysis. It represents a series system with four distinct failure modes (branches). The function has been widely used in reliability literature, particularly for testing active learning methods such as AK-MCS [Echard2011].

Analysis¶

The Four Branch function creates a non-convex failure domain with four distinct branches meeting at the origin. The failure domain is the union of four regions:

This function is particularly challenging for reliability methods because: 1. The failure domain is non-convex with four distinct components 2. The limit state function is non-smooth (minimum of four functions) 3. The probability of failure is small (rare event, ~0.45%)

It serves as a benchmark for: - Active learning reliability algorithms (AK-MCS, PC-Kriging, etc.) - Subset Sampling and NAIS algorithms - Gaussian Process / Polynomial Chaos metamodeling

Load the use case¶

Standard benchmark version (independent standard normals, p=6):

>>> from openturns.usecases import four_branch_function
>>> fb = four_branch_function.FourBranchModel()
>>> print(fb.p)
6.0
>>> print(fb.distribution)
Independent copula
X1 ~ Normal(mu=0, sigma=1)
X2 ~ Normal(mu=0, sigma=1)

Custom parameter p:

>>> fb = four_branch_function.FourBranchModel(p=7.0)
>>> print(fb.p)
7.0

Examples

>>> # Load the standard Four Branch model (p=6, standard normal inputs)
>>> fb = four_branch_function.FourBranchModel()

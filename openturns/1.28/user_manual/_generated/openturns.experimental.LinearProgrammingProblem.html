Notes

The constraint matrix is stored in compressed sparse column form (see SparseMatrix). Passing a dense Matrix converts it once and drops its zero coefficients; passing a SparseMatrix stores it as is. A large sparse problem should therefore be built from a sparse matrix, as a dense one would need bytes for constraints and variables.

getLinearConstraintCoefficients() rebuilds the dense matrix, while getSparseLinearConstraintCoefficients() returns the sparse coefficients without densifying them.

Examples

Define a mixed integer linear optimization problem with objective:

with inequality constraints:

and bound constraints:

>>> import openturns as ot
>>> import openturns.experimental as otexp
>>> cost = [1.1, 1.0]
>>> bounds = ot.Interval([0.0, 1.0], [4.0, 1e30], [True, True], [True, False])
>>> A = ot.Matrix([[0.0, 1.0], [1.0, 2.0], [3.0, 2.0]])
>>> lcb = ot.Interval([-1e9, 5.0, 6.0], [7.0, 15.0, 1e9], [False, True, True], [True, True, False])
>>> problem = otexp.LinearProgrammingProblem(cost, bounds, A, lcb)
>>> problem.setVariablesType([ot.OptimizationProblemImplementation.INTEGER, ot.OptimizationProblemImplementation.CONTINUOUS])

The same problem can be defined from the sparse constraint matrix, which only stores the non-zero coefficients. The triplets are given by their row index, their column index and their value; duplicate coordinates are summed:

>>> A = otexp.SparseMatrix(3, 2, [0, 1, 1, 2, 2], [1, 0, 1, 0, 1], [1.0, 1.0, 2.0, 3.0, 2.0])
>>> print(A.asDenseMatrix())
[[ 0 1 ]
 [ 1 2 ]
 [ 3 2 ]]
>>> problem = otexp.LinearProgrammingProblem(cost, bounds, A, lcb)
>>> print(problem.getSparseLinearConstraintCoefficients().getNbNonZeros())
5
